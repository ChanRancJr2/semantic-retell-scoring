# 高并发演进说明

本文基于当前真实架构（单 Node 进程 + 内存 Map 状态 + SQLite + 本地磁盘），说明能力边界、瓶颈与分阶段演进路线。所有数字以实际压测为准，本文给出的是架构方向而非承诺容量。

## 一、当前架构与能力边界

- 状态保存在单进程内存 `RoomManager.rooms`，进程重启即丢失实时房间（SQLite 仅保留历史数据）。
- SQLite 单文件、写入串行，适合低并发读写；不适合多实例同时写入。
- 音频存本地磁盘，只有这台机器能提供访问。
- 单 Node 进程无法利用多核，单点故障即整体不可用。

结论：本架构面向 demo（配置上限 10 房 / 50 人），在 2 核 2G 上足够；但不具备水平扩展与高可用能力。

## 二、演进路线（按优先级）

### 阶段 1：单机健壮性（改动小，先做）
- 用 PM2 cluster 或 Node `cluster` 启动多工作进程利用多核，但**内存状态需先外置**（见阶段 2），否则不同进程房间状态不一致。
- 对上传与评分接口加限流（如 express-rate-limit），防止单用户刷接口。
- 补全上传/房间接口的会话鉴权，避免仅靠前端传 userId。
- 增加优雅退出（SIGTERM 时关闭连接、停止定时器）。

### 阶段 2：状态外置、无状态化（水平扩展前提）
- 将房间状态从内存 Map 迁移到 **Redis**：房间元数据用 Hash，成员/准备用集合，阶段 deadline 用带 TTL 的键。
- 定时器（自动上传、阶段流转）改用 Redis 键过期 + 可靠延迟机制，或独立调度器，避免绑死在某一进程。
- 应用层变为无状态，可部署多副本，前面加负载均衡（SLB/Nginx）。

### 阶段 3：WebSocket 跨实例广播
- 单进程内 `io.to(code).emit` 无法到达其他实例上的成员。
- 接入 `@socket.io/redis-adapter`（Redis pub/sub），任意实例发出的事件可广播到全部实例。
- 负载均衡层需开启 WebSocket 支持；此时不强制粘性会话（Socket.IO 配合 adapter 可在重连时恢复），但开启粘性可降低握手开销。

### 阶段 4：数据与存储升级
- SQLite 迁移到 PostgreSQL/MySQL，使用连接池（如 pg.Pool），并发读写与多实例写入不再受限。
- 音频从本地磁盘迁移到对象存储（阿里云 OSS / S3），应用只存对象键；ASR 直接使用对象的公网/签名 URL，天然支持多实例。
- ffmpeg 转码这种 CPU 密集任务从 Web 服务剥离，放到独立 worker，避免阻塞事件循环。

### 阶段 5：异步任务队列与削峰
- ASR 与 LLM 调用是外部依赖，峰值时易超时或触发限流。
- 用消息队列（如 BullMQ + Redis）把“评分任务”入队，worker 按并发上限消费，配合重试、死信与超时。
- 对外部 API 做熔断与降级（失败时返回明确错误，避免请求堆积）。

### 阶段 6：可观测性与容量规划
- 指标：在线连接数、房间数、上传/评分耗时与错误率、外部 API 成功率、Redis/DB 延迟。
- 日志集中收集，关键链路加 traceId。
- 依据压测确定单副本连接数与所需副本数，再结合带宽（音频上传/下载）规划。

## 三、目标架构示意

```
手机浏览器 ──HTTPS──> 负载均衡
                        ├─ Node 应用副本(无状态) ×N
                        │     ├─ Socket.IO + Redis Adapter
                        │     ├─ Redis（房间状态/发布订阅/延迟任务）
                        │     └─ 评分任务 → 消息队列 → Worker(ffmpeg/ASR/LLM)
                        ├─ PostgreSQL（连接池）
                        └─ 对象存储 OSS（音频）
```

## 四、与现有代码的对应关系
- `server/roomManager.js`：当前内存状态的唯一入口，迁移 Redis 时仅需替换该模块内部实现，对外方法（创建/加入/重连/阶段流转/快照）保持不变即可不动业务层。
- `server/db.js`：已用 prepared statements 封装数据访问，迁移 PostgreSQL 时替换该层。
- `server/ai/index.js`：评分已模块化，适合被 worker 直接复用。
- `server/audioStore.js`：本地磁盘实现，迁移对象存储时替换其读写接口。
